# Church Finance System

A static HTML, CSS, and JavaScript prototype.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in a browser.

## Upload to GitHub

Upload `index.html`, `script.js`, `style.css`, `README.md`, and `.gitignore` to the repository root.

## Data and privacy

The app may store records in the browser where it is used. Browser-stored records are not included in this source ZIP. Do not commit real member or financial records, exported reports, or backups to a public repository.
